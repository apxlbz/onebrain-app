What OneBrain is

OneBrain reads the places where your team already works — Gmail, Google Meet notes, Google Calendar, Trello, and over a thousand other tools through their own MCP servers — and distils them into short, deduplicated facts: decisions, commitments, who knows what, and why. Every fact keeps its source. Your team searches it in the dashboard; your assistants call it directly.

Membership is by email domain. Everyone who signs in with a work Google account from the same domain shares one memory, and nobody outside it can reach a single row. A personal address gets a private memory of its own.

Connect OneBrain to Claude

OneBrain is a remote MCP server. Claude connects to it the way it connects to any connector: once, with a Google sign-in.

Before you start

  1. Sign in at onebrain.apxlbz.com with your work Google account. The first person from a domain sets the organization up; it takes about five minutes.
  2. Connect at least one source on the Sources step, so the memory has something to say.

Claude on the web, Claude Desktop, and mobile

  1. Open Settings → Connectors (on Team and Enterprise plans an Owner can add it once under Organization settings → Connectors for everyone).
  2. If OneBrain is listed in the directory, press Connect. Otherwise choose Add custom connector, name it OneBrain, and paste the address: 
    https://qlpfjeciekaqzribxlnp.supabase.co/functions/v1/mcp
  3. Press Connect and approve the Google sign-in. Claude keeps the connection alive after that.

Claude Code

claude mcp add --transport http onebrain https://qlpfjeciekaqzribxlnp.supabase.co/functions/v1/mcp

On first use, run /mcp, choose onebrain, and approve the Google sign-in. The setup wizard’s Done step also offers a one-line installer that adds the tools, turns on automatic memory hooks (recall before every prompt, remember after every session), and connects Claude Desktop on the same machine, using a personal token instead of a sign-in.

Tools

ToolWhat it doesKind
recallSearches the memory for anything the team decided, agreed, or discussed. Returns facts with their source, type, and dates. Optional filters: source, type, limit.Read
who_knowsWho on the team has demonstrated knowledge of a topic, ranked by the facts that prove it.Read
graph_neighborsThe relationships around a person, project, product, or system, out to a chosen depth.Read
list_memoryWhich sources and kinds of facts the memory holds, with counts.Read
rememberSaves a decision, fact, or note from the conversation so everyone has it next time. Adds only; never edits or deletes.Write

Read tools carry the readOnlyHint annotation and run without a per-call confirmation in Claude. remember is the only tool that writes, and Claude asks before calling it.

Example prompts

  • “Who knows about the Stripe integration?”
  • “What were Tuesday’s action items?”
  • “Remember that the launch moved to October 14.”

Other assistants

Any MCP client that speaks streamable HTTP takes the same address. Cursor, VS Code, Windsurf, and Gemini CLI setups are filled in for you on the setup wizard’s Done step, including one-click links for Cursor and VS Code. Scripts and hooks authenticate with a personal token, minted on the same page or in Settings, sent as Authorization: Bearer <token>.

Your data

  • Access is read-only for every connected source; OneBrain cannot modify or delete anything in Gmail, Drive, Calendar, Trello, or a remote source.
  • Google user data is handled under the Google API Services User Data Policy, including the Limited Use requirements. It is never sold or used for advertising.
  • Secrets are stripped on the way in: API keys, passwords, and tokens are never written to memory.
  • You can take it all back. Settings offers a full JSON export, a one-click purge of the memory, and deletion of the organization, which revokes each source’s access at the provider.

Troubleshooting

  • “Couldn’t reach the MCP server.” Check the address ends in /functions/v1/mcp with no trailing slash.
  • The sign-in loops. Sign in at onebrain.apxlbz.com first with the same Google account, then connect again.
  • Answers are empty. The memory fills within a minute of connecting a source. The dashboard’s Sources tab shows each connection’s state, when it was last verified, and any trouble.
  • A source shows “error”. Open Setup → Sources and click that source: OneBrain re-checks what it reads and fixes it.
  • Anything else: or@apxlbz.com.
