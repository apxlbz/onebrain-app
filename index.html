Why it answered

Every answer shows its work.

Other tools hand you ten results and let you guess. OneBrain shows which search found each one, where it ranked, and what moved it — so you can tell a real match from a lucky one.

  • Which search found it, and where it ranked
  • What the reranker moved, and by how much
  • Every weighting that touched the score

When it changes

It forgets on purpose.

Change a price, a plan or an owner and the old fact is retired — search stops returning it, instead of leaving it one row below the new one waiting to mislead somebody.

Nothing is lost: you keep the trail of what it said, when it changed, and what replaced it.

How it works

Three steps. You run none of them.

  1. 01

    Capture

    Gmail, Meet transcripts, Calendar and Trello land in a log that is only ever added to — along with the coding sessions your team runs and any of 1,200+ other tools you connect. Nothing gets rewritten. Nothing gets thrown away.

  2. 02

    Distil

    Each one becomes single facts, tied to the people and projects they name. API keys and passwords are stripped before anything is saved.

  3. 03

    Recall

    Ask in the browser, or let Claude ask for you. Same answer either way, with the same explanation attached.

Your data

You can take it all back.

You are about to point this at everything your company writes down. The first question is always the same one, so here is the answer.

  • Leaving takes one click. Export the whole thing as JSON, or delete anything by id, by source, or by what it says.
  • Secrets never get written. API keys, passwords and tokens are stripped on the way in, before the first row is saved.
  • Nothing crosses organizations. Your email domain decides which memory you get, and every single query carries that scope.
  • Every fact traces back. The original transcript is kept unchanged, so you can always read what was actually said.

How OneBrain uses your Google data

Access is read-only, per member, and revocable at any time from your Google account or from OneBrain’s Sources page.

Gmail
Reads recent work mail (promotions and social are excluded) to capture decisions and commitments made over email. Message content is processed into short factual notes; mailboxes are never shared between members.
Google Drive
Reads Google Meet notes and transcripts stored in your Drive so meetings become part of the shared memory.
Google Calendar
Reads events, attendees and dates to anchor the memory in time — who met whom, and when.

OneBrain’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. We never sell your data or use it for advertising.

Wire it up

One line, wherever you work.

An agent with tools and no memory will confidently tell you something your team decided against in March. Point it here and it checks first — same URL and token in your terminal, your editor, or a job running at 3am.

$ claude mcp add --scope user --transport http onebrain \
    __MCP_URL__

For everyone on the team who works in the terminal. Sign in with Google on the first call; hooks make memory automatic — nobody has to remember to say “remember this”.

{
  "mcpServers": {
    "onebrain": {
      "type": "http",
      "url": "__MCP_URL__"
    }
  }
}

Any MCP client takes the same URL and signs in the same way. Nothing about OneBrain is specific to one harness.

$ curl -s __API_URL__/v1/recall \
    -H "Authorization: Bearer $ONEBRAIN_TOKEN" \
    -H 'Content-Type: application/json' \
    -d '{"query":"why did we not adopt cognee"}'

For agents that never touch a laptop — CI jobs, cron, a service in your cluster. Plain REST with a personal token from Settings, so a shell hook is one curl.
