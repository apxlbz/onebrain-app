It forgets on purpose.

Change a price, a plan or an owner and the old fact is retired — search stops returning it, instead of leaving it one row below the new one waiting to mislead somebody.

Nothing is lost: you keep the trail of what it said, when it changed, and what replaced it.

Three steps. You choose what is kept.

  1. Remember

    You, or an agent you connected, explicitly stores a preference, decision, or fact. Automatic ingestion is off: Gmail, Meet, Calendar, and Trello are not read on their own. The note is kept as you sent it.

  2. Distil

    Each note becomes single facts, tied to the people and projects they name. API keys and passwords are stripped before anything is saved.

  3. Recall

    Ask in the browser, or let another agent ask. Same private memory either way, with the same explanation attached.

You can take it all back.

You are about to keep a memory your agents can read. The first question is what happens to it, so here is the answer.

  • Leaving takes one click. Export the whole thing as JSON, or delete anything by id, by source, or by what it says.
  • Secrets never get written. API keys, passwords and tokens are stripped on the way in, before the first row is saved.
  • Private by default. A fresh sign-in is a personal memory only you and the agents you connect can read. A shared space is opt-in, and only an existing member can open it.
  • Every fact traces back. The note you remembered is kept unchanged, so you can always read what was stored.

Google user data disclosure

This block is the disclosure for Google API access. It is not a product feature. Automatic ingestion is off: OneBrain does not read Gmail, Drive, or Calendar on its own. If a Google connection is authorized, including a legacy grant, access is read-only, limited to that member, and revocable from the Google account.

Gmail
Authorized access is read-only and limited to recent work mail (promotions and social excluded), for decisions and commitments made over email. Message content is processed into short factual notes. Mailboxes are never shared between members.
Google Drive
Authorized access is read-only and limited to Google Meet notes and transcripts stored in Drive.
Google Calendar
Authorized access is read-only and limited to events, attendees, and dates.

OneBrain’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. We never sell your data or use it for advertising.

One line, wherever you work.

Mint one token, then one line. Point an agent here and it can recall what you already remembered — the terminal, the editor, or a job running at 3am.

$ curl -fsSL __INSTALL_SH__ | ONEBRAIN_API_KEY="$ONEBRAIN_API_KEY" bash -s -- claude-code

Mint the token in Settings → Connect your tools and export it as ONEBRAIN_API_KEY. Production is https://onebrain.apxlbz.com/agent-install.sh. Dev is the same command from https://onebrain-dev.apxlbz.com/agent-install.sh.

Same script. codex and mcp are the other hosts.
