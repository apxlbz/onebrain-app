Install OneBrain

Mint a personal token, then copy one line. No wizard. Each line runs the live agent-install.sh for this site. The key stays in ONEBRAIN_API_KEY and is not written into the host config.

Sign in, then Settings → Connect your tools → Mint my token. Production is https://onebrain.apxlbz.com/agent-install.sh. Dev is the same command from https://onebrain-dev.apxlbz.com/agent-install.sh.

Clients that sign in themselves

These clients can open a Google sign-in on first connect. The address is __MCP_URL__. Nothing in this section carries a token. See Connect to Claude.

Claude Code

The API-key line above is the one to copy. Without a token, add the server, connect, then log in. claude mcp get onebrain (or /mcp in a session) caches the metadata URL from the 401 header.

Any other MCP client

    
Anything that speaks streamable HTTP takes the same address. Point it
      here; a client with no OAuth support of its own can instead authenticate
      using a personal token from Settings (once signed in), passed however
      that client's own config expects a bearer credential.
